# Adarsh Studio Management System

A web-based studio management application developed using ASP.NET Core MVC and jQuery for managing customers, bookings, invoices, and studio operations.

## Tech Stack

- ASP.NET Core MVC
- C#
- Entity Framework
- SQL Server
- jQuery
- AJAX
- Bootstrap
- HTML5 & CSS3

## Key Features

- Customer Management
- Booking Management
- Invoice Generation
- Dashboard & Reports
- Authentication & Authorization

## Project Structure

Controllers → Business Logic

Models → Data Models

Views → Razor UI

wwwroot/js → jQuery & AJAX
